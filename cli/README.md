# svitlo-flasher

Утиліта для прошивки ESP32 і передачі налаштувань Wi-Fi для SvitloBot Monitor. Працює на macOS, Windows і Linux.

```bash
pip install .
```

```bash
svitlo-flasher flash --ssid "НазваМережі" --key "ключ-доступу"
```

Повна інструкція — у [README.md](../README.md) в корені репозиторію.
